Geopotential height at interface
================================

* **Description**: Produces geopotential height at layer interfaces from geopotential levels.
* **Name**: GeopotentialHeightAtInterface_A
* **Variable produced**: geopotential_height_levels
* **Input Variables**: geopotential_levels
* **Trajectory Variables**: None
* **Number of Levels**: Same as geopotential_levels
* **FunctionSpace**: Same as geopotential_levels 
* **hasTLAD**: True
* **hasNL**: True
* **Required Configuration Variables**: standard_gravitational_acceleration
* **Optional Parameters**: None
